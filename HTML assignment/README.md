# Hospital Appointment Booking System

A unified digital platform designed to streamline healthcare access in Rwanda by connecting patients with specialized doctors across leading hospitals.

## Project Structure

The project is organized into the following directories:

- **HTML/**: Contains all the web pages of the application.
  - `index.html`: The landing page with an overview of services and partner hospitals.
  - `login.html`: Patient login and registration entry point.
  - `patient_info.html`: The appointment booking form where patients enter their details and select doctors.
  - `admin_login.html`: Secure login portal for hospital staff and administrators.
  - `admin_workspace.html`: A comprehensive dashboard for managing appointments, patients, and schedules.
- **CSS/**: Contains the styling for the entire application.
  - `styles.css`: Global and page-specific styles, including responsive design for mobile devices.
- **images/**: Stores visual assets used in the application.
  - `top-largest-independent-hospitals-header.jpg`: Used for hero and panel backgrounds.

## Key Features

- **Instant Scheduling**: Easy-to-use form for booking appointments.
- **Admin Dashboard**: Real-time management of booking requests and patient databases.
- **Responsive Design**: Optimized for both desktop and mobile viewing.
- **Integrated Doctor Schedules**: View weekly availability of specialists directly on the booking page.

## How to Run

Simply open `HTML/index.html` in any modern web browser to start exploring the platform.
